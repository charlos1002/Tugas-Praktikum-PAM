## 💻 Cara Menjalankan Aplikasi

Berikut langkah-langkah untuk menjalankan proyek ini di **Android Studio**:

1. **Clone atau Unduh Repositori**:
   * unduh file ZIP repositori dari GitHub dan ekstrak di komputer Anda.

2. **Buka Proyek di Android Studio**:
   * Buka aplikasi **Android Studio**.
   * Pilih menu **Open** lalu arahkan ke lokasi folder:  
     `Tugas-Praktikum-PAM/Minggu 2/Tugas2PAM`[cite: 7, 8].
   * Tunggu hingga proses **Gradle Sync** selesai sepenuhnya.

3. **Jalankan Aplikasi**:
   * **Menggunakan Emulator (Virtual Device)**:
     1. Buka **Device Manager** di Android Studio.
     2. Pilih atau jalankan Virtual Device (misal: *Pixel 7 / Pixel 8*).
     3. Klik tombol **Play (▶)** di toolbar atas atau tekan tombol `Shift + F10`.
   * **Menggunakan Perangkat Android Fisik**:
     1. Aktifkan **USB Debugging** di HP Android Anda (*Settings > Developer Options*).
     2. Hubungkan HP ke laptop/komputer menggunakan kabel data USB.
     3. Pilih nama HP Anda pada menu *Device Selector* di toolbar atas Android Studio.
     4. Klik tombol **Play (▶)** untuk menginstal dan menjalankan aplikasi.
